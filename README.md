# NO₂ Pollution Analysis Using Sentinel-5P & Machine Learning

This project analyzes urban nitrogen dioxide (NO₂) pollution using Sentinel-5P TROPOMI satellite data and Python-based visualization techniques. The workflow includes extracting NO₂ data in NetCDF format, preprocessing it using tools like xarray, numpy, and pandas, and generating spatial and temporal visualizations through matplotlib and cartopy. The project also explores machine learning models such as Random Forest and Gradient Boosting for preliminary pollution forecasting, with deep learning techniques like LSTM and CNN referenced for future enhancements.

Visual outputs include NO₂ heatmaps, monthly trends, spatial pollution clusters, and distribution plots, providing a clear picture of urban air quality patterns. The study is inspired by recent research, including Blanco et al. (2024) and Grzybowski et al. (2023), and demonstrates how satellite data and open-source tools can be used to build scalable pollution monitoring systems.
