# 🌍 NO₂ Pollution Analysis Using Sentinel-5P & Machine Learning

This project analyzes urban NO₂ pollution using Sentinel-5P TROPOMI satellite data and applies machine learning techniques to understand spatial and temporal pollution patterns. The workflow includes data extraction, preprocessing, visualization, and model-based analysis using Jupyter Notebook. The project highlights how satellite data can be used for scalable, low-cost environmental monitoring in urban regions.

# 🛰 Dataset

Sentinel-5P (TROPOMI) NO₂ Dataset

Tropospheric NO₂ column density

Source: Copernicus Open Access Hub & Google Earth Engine

Format: NetCDF

# ⚙️ Project Overview

The project uses Sentinel-5P NO₂ data to observe pollution variations across cities. Data is cleaned, filtered using QA flags, and visualized through heatmaps and time-series plots. Machine learning models like Random Forest, Gradient Boosting, and Linear Regression are applied to study trends and basic forecasting. Visual analysis clearly identifies pollution hotspots and seasonal patterns.

📊 Techniques Used

ML Models: Random Forest, Gradient Boosting, Linear Regression

DL Techniques (referenced): LSTM, CNN, ConvLSTM

Tools: Python, Jupyter Notebook, xarray, numpy, matplotlib, cartopy
